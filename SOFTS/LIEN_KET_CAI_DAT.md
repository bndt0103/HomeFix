# Phần mềm cần dùng

Node.js 24 LTS x64: https://nodejs.org/en/download

SQL Server Express/Developer: https://www.microsoft.com/en-us/sql-server/sql-server-downloads

ODBC Driver for SQL Server x64: https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server

SSMS: https://learn.microsoft.com/en-us/ssms/install/install

VS Code: https://code.visualstudio.com/download

Android Studio (chỉ để tự build APK): https://developer.android.com/studio

Capacitor Android: https://capacitorjs.com/docs/android

Không kèm bộ cài hệ điều hành/SQL/SDK dung lượng lớn. Không cần cài lại SQL Server trên máy đã kết nối được bằng SSMS. Phiên bản thực tế đã kiểm thử được ghi trong báo cáo; chọn Node LTS thay vì Current để bám môi trường thực hành.
