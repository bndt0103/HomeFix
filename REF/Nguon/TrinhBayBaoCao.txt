=== Slide 4 ===
Định dạng báo cáo
Báo cáo phải được trình bày ngắn gọn, rõ ràng, mạch lạc, sạch sẽ, không được tẩy xóa, có đánh số trang
Font chữ: VNI-Times hoặc Times New Roman, kích thước(size) 13. Hệ soạn thảo MS Word.
Giãn dòng (line spacing) đặt ở chế độ 1.0 lines.
Lề trên 3 cm, lề dưới 3 cm, lề trái 3 cm, lề phải 2 cm.

=== Slide 5 ===
Định dạng báo cáo (tt)
Số thứ tự của các chương, mục được đánh số bằng hệ thống số Ảrập, không dùng số La mã. Các mục và tiểu mục được đánh số bằng các nhóm hai hoặc ba chữ số, cách nhau một dấu chấm: số thứ nhất chỉ số chương, chỉ số thứ hai chỉ số mục, số thứ ba chỉ số tiểu mục.
Ví dụ:
	Chương 3 …
		3.1. …
			3.1.1. …
			3.1.2. …
		3.2. …

Quy định về nộp đĩa CD
Folder DOC: lưu file word toàn văn báo cáo (dạng .DOC hoặc .DOCX).
Folder PDF: lưu file PDF toàn văn báo cáo.
Folder PPT: lưu file Powerpoint trình chiếu (nếu có).
Folder SRC: chứa toàn bộ mã nguồn của chương trình, kể cả file script SQL hoặc database (nếu có).
